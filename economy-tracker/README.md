# The Broker of Wakfu Street

Rastreador de economía manual para Wakfu: lista de vigilancia de objetos, snapshots manuales de precio/cantidad del Mercadillo, historial de ventas propias y un cuaderno de ideas de nicho.

Un único archivo HTML/JS (`wakfu-economy-tracker.html`) con almacenamiento persistente vía `window.storage` (Claude Artifacts). Sin backend, sin base de datos externa, sin automatización del juego — cero riesgo de baneo, toda la entrada de datos es manual.

Ver `PROJECT_INSTRUCTIONS.md` para el historial de cambios y las convenciones de este proyecto.
